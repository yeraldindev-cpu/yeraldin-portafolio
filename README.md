## Stack del sitio

- HTML5 semántico

## Estructura del proyecto

```text
/
│── index.html
│
├── assets/
│   ├── css/
│   │      style.css          # estilos base, layout, componentes
│   │      responsive.css     # media queries
│   │
│   ├── js/
│   │      main.js            # navegación, toggles, botón volver arriba
│   │      animations.js      # scroll reveal
│   │
│   ├── images/
│   │      hero/              # gráficos del hero (si se agregan)
│   │      profile/           # foto de perfil
│   │      projects/          # capturas de cada proyecto
│   │      technologies/      # iconos propios (si no se usa Devicon)
│   │      icons/             # iconografía general
│   │
│   ├── fonts/                 # fuentes locales (si se decide no usar Google Fonts CDN)
│   │
│   └── favicon/               # favicon.ico y variantes
│

│
└── favicon.ico
```
