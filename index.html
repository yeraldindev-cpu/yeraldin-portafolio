TAM — Tecnología a tus Manos

Administradora General del proyecto. Participé en todas las etapas del desarrollo, desde la planificación, organización y coordinación del equipo hasta la implementación y entrega del sistema.

Proyecto académico desarrollado por un equipo de 18 desarrolladores para construir un ecosistema de comercio electrónico integrado: una plataforma web para clientes, un sistema administrativo de escritorio para la gestión del negocio y una aplicación móvil que facilita el acceso a las principales funcionalidades desde cualquier lugar.

Proyecto en equipo
Plataforma Web Sistema Administrativo Aplicación móvil
Proyecto académico E-commerce 2026 Equipo de 18 desarrolladores

Problema

Muchos comercios electrónicos de tecnología ofrecen catálogos amplios que dificultan la comparación entre productos y hacen más compleja la toma de decisiones durante el proceso de compra.

Solución

Se desarrolló un ecosistema compuesto por una plataforma web para clientes, un sistema administrativo de escritorio y una aplicación móvil que permiten gestionar el negocio y ofrecer una experiencia de compra completa.

Funcionalidades principales

  • Autenticación de usuarios y recuperación de contraseña mediante código de verificación.
  • Catálogo de productos con filtros avanzados.
  • Comparador inteligente de productos.
  • Carrito de compras.
  • Lista de favoritos.
  • Perfil de usuario editable.
  • Gestión de pedidos.
  • Formulario de contacto.

INVERTI — Sistema de Gestión de Inventario

Proyecto personal desarrollado de forma integral.

Sistema web desarrollado para facilitar la gestión de inventario, productos, categorías y movimientos de stock en pequeños negocios.

Funcional
Proyecto personal Sistema web 2026 Registro DNDA

Problema

Muchas pequeñas y medianas empresas gestionan su inventario mediante registros manuales o hojas de cálculo, lo que dificulta el control del stock, aumenta los errores y limita la trazabilidad de la información.

Solución

INVERTI centraliza toda la administración del inventario en una plataforma web que permite controlar productos, movimientos, usuarios y alertas de stock desde un único panel administrativo.

Funcionalidades

  • Dashboard con indicadores en tiempo real.
  • Gestión de productos, categorías y subcategorías.
  • Control de entradas, salidas y ajustes de inventario.
  • Administración de usuarios mediante roles.
  • Alertas automáticas por bajo nivel de existencias.
  • Historial completo de movimientos para garantizar trazabilidad.

Resultados

  • Sistema completamente funcional.
  • CRUD completo de productos y categorías.
  • Autenticación y control de accesos por rol.
  • Base de datos relacional con trazabilidad total.

Terra & Brasa — Landing Page de Restaurante

Diseño & desarrollo Frontend · Proyecto de portafolio

Finalizado
Proyecto personal Landing page 2026

Problema

El restaurante (ficticio, de portafolio) no tiene presencia digital que comunique su identidad ni permita reservar mesa en línea.

Solución

Una landing cálida y elegante con menú, galería, testimonios y un formulario de reservas con validación y envío real vía Formspree.

Funcionalidades

  • Navbar fija con scroll suave
  • Formulario de reservas con validación
  • Envío de reservas vía Formspree
  • Simulación de disponibilidad por fecha (localStorage)
  • Carrusel de testimonios y galería
  • Integración con Google Maps
  • Diseño responsive mobile-first

Resultado

  • Landing 100% responsive y accesible.
  • Sistema de reservas funcional sin backend propio.
  • Identidad visual propia (paleta, tipografía y tono).
